# Sales Performance Dashboard | Power BI

## 📊 Project Overview

Interactive Power BI dashboard designed to analyze sales,
profitability, salesperson performance, products, and trends.

## 🎯 Business Questions

- How are sales performing over time?
- Which regions generate the most sales?
- Which salespeople achieve their targets?
- Which products generate the highest profit?
- Which products generate high sales but low/negative profit?

## 🔍 Key Insights

- Bikes represent the largest sales category.
- Some products generate high sales but negative gross profit.
- Sales performance varies significantly across salespeople.
- Sales trends show substantial year-over-year variation.
